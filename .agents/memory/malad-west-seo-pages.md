description: Durable conventions for the Sentra Clinic static SEO content pack.
---

Malad West landing pages should remain standalone WordPress-ready HTML, use approved existing Sentra Clinic image URLs, and be generated from page data rather than hand-edited copies. Each long-form page should preserve genuinely distinct search intent, 2,000+ visible words, canonical/meta tags, MedicalClinic/Breadcrumb/FAQ structured data, internal links, and a preview check.

**Why:** The project is a static content pack whose pages are pasted into Elementor; duplicated local pages and missing clinical context create SEO and publishing risk.

**How to apply:** When adding or editing a landing page, update the relevant generator data, run its built-in word-count check, validate rendered HTML/schema/image count, restart the static workflow, and inspect a browser preview. Clinical claims, fees, hours, routes, and emergency availability still require clinic confirmation before publication.
